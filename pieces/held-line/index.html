Held Line

A frantic field of hatching probes the whole canvas forever. One calm contour never gets touched — not because it's protected, but because everything that would touch it is quietly turned away first.
—
The pale contour is drawn identically every frame from fixed points — it never jitters, never redraws differently. Drag the buffer to zero and the scribble field will crowd right up against the line, but the "closest a mark has ever landed" reading will still never go below the buffer value: the exclusion is a hard test run before a mark exists, not a visual accident.
